# AI Agent Documentation Assets

This folder stores assets for the AI Agent user guide.

## Screenshots

To embed screenshots into the generated `.docx`, place image files here:

- `docs/ai-agent/screenshots/01-status.png`
- `docs/ai-agent/screenshots/02-agents.png`
- `docs/ai-agent/screenshots/03-settings.png`
- `docs/ai-agent/screenshots/04-chat-test.png`

Then regenerate the document:

```bash
python3 tools/generate_ai_agent_user_guide_docx.py
```
