Widget Group Routing Test

Test Configuration

This page is configured with groupId: 1

When you start a chat on this page, the conversation should be assigned to group ID 1 (General).

How to Test

  1. Make sure you have at least one group created in the admin panel (Settings > Team > Groups)
  2. Note the ID of the group you want to test with
  3. Update the groupId value in the script below to match your test group ID
  4. Open this page and start a chat
  5. Check the conversation in the admin panel - it should be assigned to the specified group

Testing Different Groups

Create multiple copies of this file with different groupId values to test routing to different groups:

  • test-group-widget-1.html - groupId: 1
  • test-group-widget-2.html - groupId: 2
  • test-group-widget-3.html - groupId: 3
